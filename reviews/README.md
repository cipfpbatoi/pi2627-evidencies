# Esborranys de revisió docent PI

El dashboard guarda ací, fora del control de versions, les matrius individuals vinculades a cada commit revisat. Poden contindre identificadors de l'alumnat, observacions docents i dates de reobservació.

- No commeteu ni publiqueu els fitxers de `reviews/pi/`.
- Limiteu l'accés del directori a l'usuari del servei i al professorat autoritzat.
- Incloeu-lo en les còpies de seguretat mentre les revisions continuen vigents.
- Exporteu el CSV o JSON quan calga traslladar el registre a Aules.
- Aules continua sent el registre oficial; estos fitxers són esborranys de treball i no contenen qualificacions.
